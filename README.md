# 台東四天三夜家庭旅行

本機靜態網站，參照既有廣島行程的每日時間軸、三餐、地圖及來源結構重新製作。沒有修改廣島原檔，沒有自動發佈或推送 GitHub。

## 開啟與分享

1. 解壓縮完整資料夾。
2. 雙擊 `index.html`，或 Windows 的 `開啟台東行程.cmd`。
3. 傳給家人時傳整個 ZIP，不只傳一個 HTML；`assets/` 是離線照片，`data.js`、`app.js` 與 `style.css` 需一起保留。

文字、照片及晴雨切換可離線使用。Google Maps、原始來源及評論需要網路。無需安裝套件、登入、連同一個 Wi-Fi 或開對外伺服器。

## 內容範圍

- 2026/11/30–12/3，四大一小、全家蛋奶素，三晚固定夏雪居。
- 四天晴天與雨天行程；D3另有豪雨不跑縱谷版。
- 每天三餐、D4分流後兩組晚餐、營業時間／星期檢查、替代餐廳。
- 評分為公開頁面收錄Google資料，非即時Google查詢；各餐廳附評分來源與營業來源。
- 所有景點及餐廳附Google Maps，時間軸附上一站到下一站動線。
- 12/3晴雨固定知本站；423次13:07–17:53為現行班表參考，並非已買車票或旅行日運行確認。
- 大字閱讀、點餐說明複製、列印晴雨兩版。

## 證據與限制

一般營業時間已搜尋並對照餐期與星期，臨休、正餐供應及五人座位無法從一般時段保證；未代打電話、代訂位或買票。衝突與不定休留在餐廳欄，不能當成已確認開門。

照片來源見網站頁尾。用於私人行程參考；如公開商用或再次散布圖片，先核對原站授權。照片不是本次日期的天氣或稻田保證。
